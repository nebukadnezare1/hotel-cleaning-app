# 🧹 Hotel Cleaning App

Application web de gestion du nettoyage des chambres d’hôtel.  
Frontend en **HTML, CSS, JavaScript**, backend en **Flask (Python)**.  
Elle permet la création de comptes, la gestion des chambres, la sauvegarde des données et la génération de rapports PDF.

---

## 🚀 Fonctionnalités

- Création et connexion d’utilisateurs (`users.json`)
- Gestion des chambres (ajout, suppression, statut, etc.)
- Sauvegarde automatique par utilisateur (`data_nomuser.json`)
- Génération de rapports PDF

💻 Technologies

Frontend : HTML5, CSS3, JavaScript
Backend : Python (Flask)
